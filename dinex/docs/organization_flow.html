Key insight: Users are linked to organizations via OrganizationMembership (with a role). They are linked to locations via LocationMembership (access control). This enables:

  • A user to belong to multiple organizations with different roles
  • Fine‑grained location access (e.g., a manager can only see their assigned locations)
  • Entitlements (services) are linked to locations, not organizations
